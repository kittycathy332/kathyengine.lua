Leather Engine Functions

Leather Engine (LE) mod script compatibility layer API.
Registered by KathyEngine LeatherLuaScript.hx (384 functions in total); available to ALL mods when leatherScriptCompat is not off. auto routes each script by its content: LE-API scripts run on the LE runtime, Psych-API scripts on the Psych runtime (they can coexist in one mod); official/lts force every script onto the LE runtime; off keeps everything on Psych.
Sources: Official 0.5.0 ModchartUtilities.hx (212) and LTS 1.1.9 LuaScript.hx (373).
Version semantics: LTS-only functions are removed in official mode (calling them errors with nil); official-only exist only in Official; both means available in both. MODCHARTING_TOOLS stubs only log a message (Kathy has no such system).

Kathy adaptations: no standalone strumLine object (setStrumlineX/Y move members directly); note speed field is multSpeed; flixel 5.9 has no FlxTween.id (tweens registered with auto-increment keys); FlxSound loop field is looped; BaseStage.add is package-private (stage objects attach to PlayState); SwagSong has no character position fields (getOriginalCharX/Y return 0).
