Kathy Engine - Lua Script API

Character Functions

Functions to change a Character Group's position and make them dance.

characterDance

characterDance(character:String):Void

Makes a character play their idle animation if possible.
This is different from "playAnim" because it cycles through "danceLeft" and "danceRight" automatically for characters.

  • character - "bf", "dad" or "gf".

getCharacterX

getCharacterX(character:String):Float

Returns a Character Group's X, this will affect all character positions, even if you use "Change Character" event.

  • character - "bf", "dad" or "gf".

getCharacterY

getCharacterY(character:String):Float

Returns a Character Group's Y, this will affect all character positions, even if you use "Change Character" event.

  • character - "bf", "dad" or "gf".

setCharacterX

setCharacterX(character:String, value:Float):Void

Sets a Character Group's X, this will affect all character positions, even if you use "Change Character" event.

  • character - "bf", "dad" or "gf".
  • value - Value to set it to.

setCharacterY

setCharacterY(character:String, value:Float):Void

getPlayingCharacterAnim Kathy Engine

getPlayingCharacterAnim(character:String):String

Returns the name of the animation currently playing on the character. Empty string if none.

  • character - "bf"/"boyfriend", "dad"/"opponent", "gf"/"girlfriend".

Examples:

  • local anim = getPlayingCharacterAnim('boyfriend') - Returns e.g. 'singLEFT' or 'idle'.
  • if getPlayingCharacterAnim('bf') == 'singLEFT' then debugPrint('BF is singing left!') end

characterExists Kathy Engine

characterExists(name:String):Bool

Checks whether a character with the given name exists in the assets or in any loaded mod folder.

  • name - Character name (e.g. "pico", "mom", "sister").

Examples:

  • if characterExists('pico') then debugPrint('Pico is available!') end
