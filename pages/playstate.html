Kathy Engine - Lua Script API

PlayState Functions

General functions related to the Game State, Song and Cutscenes.

startCountdown

Usage: startCountdown()

Starts the countdown, should be used after finishing your Pre-Song Cutscene.

endSong

Usage: endSong()

Ends the song, can be cancelled through the Lua/HScript callback "onEndSong" to make cutscenes.

getSongPosition

Usage: getSongPosition()

Returns the current song position, in milliseconds.

restartSong

restartSong(?skipTransition:Bool = false):Void

Restarts the Song, pretty self explanatory.

  • skipTransition (Optional) - Skips fade in/out transition, defaults to false.

exitSong

exitSong(?skipTransition:Bool = false):Void

Quits the Song and goes back to Freeplay/Story Mode based on where you started.

  • skipTransition (Optional) - Skips fade in/out transition, defaults to false.

loadSong

loadSong(?name:String = null, ?difficultyNum:Int = -1):Void

Loads the chart for a song.

  • name (Optional) - Song Name (ex. "Bopeebo", "Lit Up").
  • difficultyNum (Optional) - Week's Difficulty Number (0 = Easy, 1 = Normal, 2 = Hard), use -1 to keep it the same as current.

triggerEvent

triggerEvent(name:String, ?value1:String = '', ?value2:String = ''):Bool

Calls an event and uses two arguments for it, exactly like the Chart Editor does.
Should always return "true".

  • name - Event Name.
  • value1 (Optional) - Does the same as what the Event says in the Chart Editor.
  • value2 (Optional) - Does the same as what the Event says in the Chart Editor.

Examples:

  • triggerEvent('Hey!', 'BF', 0.6) - Calls "Hey!" event.

setHealthBarColors

setHealthBarColors(left:String, right:String):Void

Changes Health Bar colors.

  • left - Color hexadecimal string or color name for the left side of the bar.
  • right - Color hexadecimal string or color name for the right side of the bar.

Examples:

  • setHealthBarColors('FF0000', '00FF00') - Makes left side red and right side lime.
  • setHealthBarColors('red', 'lime') - Same as above, but using color names.

setTimeBarColors

setTimeBarColors(left:String, right:String):Void

Changes Time Bar colors.

  • left - Color hexadecimal string or color name for the left side of the bar.
  • right - Color hexadecimal string or color name for the right side of the bar.

Examples:

  • setTimeBarColors('FF0000', '00FF00') - Makes left side red and right side lime.
  • setTimeBarColors('red', 'lime') - Same as above, but using color names.

startDialogue

startDialogue(dialogueFile:String, ?music:String):Void

Loads a Dialogue .JSON inside the Chart folder, handles translation loading automatically.

  • dialogueFile - Dialogue file .JSON name.
  • music (Optional) - Plays a background music inside "music/" folder.

Examples:

  • startDialogue('dialogue') - Loads "dialogue.json" inside the chart folder, will prefer "dialogue_pt-BR.json" if you're playing on Portuguese (Brazil).
  • startDialogue('dialogue', 'breakfast') - Same as above, but plays "Breakfast" as background music.

startVideo

startVideo(videoFile:String, ?canSkip:Bool = true, ?forMidSong:Bool = false, ?shouldLoop:Bool = false, ?playOnLoad:Bool = true):Void

Plays a Video Cutscene.

  • videoFile - Video .MP4 file located inside "videos/" folder, don't include the extension!
  • canSkip (Optional) - Allows the video to be skipped by holding down Enter for a second. Defaults to true.
  • forMidSong (Optional) - Doesn't start/finish song after the video ends, needed for mid-song cutscenes. Defaults to false.
  • shouldLoop (Optional) - Video will repeat once finished. Defaults to false.
  • playOnLoad (Optional) - Videos plays instantly after loading. Defaults to true.

Examples:

  • startVideo('test_video') - Plays the video mods/My-Mod/videos/test_video.mp4.

🔔 Callbacks / on* Events

Callbacks are special Lua/HScript functions automatically called by the engine at specific moments.
To hook into one, just define a function with that name in your script.

Return Function_Stop from a stoppable callback to prevent the default engine behavior.

Creation & Lifecycle

onCreate

function onCreate()

Called when PlayState.create() begins, before all game objects are initialized.

onCreatePost

function onCreatePost()

Called after PlayState.create() finishes — all characters, HUD, notes and variables are ready.

Countdown

onStartCountdown

function onStartCountdown() → can return Function_Stop

Fired before the countdown starts. Return Function_Stop to prevent the countdown from starting (useful for pre-song cutscenes).

onCountdownStarted

function onCountdownStarted()

Fired when the countdown actually begins playing audio/visuals.

onCountdownTick

function onCountdownTick(count:Int)

Fired on each countdown number change (3 → 2 → 1 → GO!). (KathyEngine: also fires on GO!)

onEndCountdown Kathy Engine

function onEndCountdown()

Fired when Ready-Set-Go finishes and the song is about to start playing. More precise than onSongStart.

Song Progress

onSongStart

function onSongStart()

Fired when the song music actually starts playing.

onEndSong

function onEndSong() → can return Function_Stop

Fired when the song ends (reaches the end of the chart). Return Function_Stop to prevent the default results screen.

onSectionHit

function onSectionHit(section:Int)

Fired when the song reaches a new section (song BPM changes).

Pause & Death

onPause

function onPause() → can return Function_Stop

Fired when the game pauses. Return Function_Stop to prevent pausing.

onResume

function onResume()

Fired when the game resumes from pause.

onDeath Kathy Engine

function onDeath()

Pure notification fired when health reaches 0 (before any death flow begins). Cannot be stopped — use onGameOver or onCustomGameOver for that.

onGameOver

function onGameOver() → can return Function_Stop

Fired when the death flow is about to start. Return Function_Stop to block the entire death (no music stop, no stunned character, no GameOverSubstate).

onCustomGameOver Kathy Engine

function onCustomGameOver() → can return Function_Stop

Fired after the default death flow has started (character stunned, music paused) but BEFORE GameOverSubstate opens.
Return Function_Stop to prevent the default GameOverSubstate — useful for making custom death/end screens.
Unlike onGameOver, the music and character are already in their death state when this fires.

Note Judgement

onSpawnNote

function onSpawnNote(index:Int, noteType:String, isSustainNote:Bool, strumTime:Float)

Fired when a note enters the play field (on-screen).

goodNoteHit

function goodNoteHit(index:Int, noteType:String, isSustain:Bool)

Fired when the player hits a note (any judgement: Perfect/Great/Good/Bad/Shit).

opponentNoteHit

function opponentNoteHit(index:Int, noteType:String, isSustain:Bool)

Fired when the opponent hits a note.

noteMiss

function noteMiss(index:Int, noteType:String)

Fired when the player misses a note.

ghostNoteMiss Kathy Engine

function ghostNoteMiss(index:Int)

Fired when a ghost note (past the strum line) is missed.

Score

preUpdateScore

function preUpdateScore(miss:Bool) → can return Function_Stop

Fired BEFORE the score/hit/miss counters are updated. Return Function_Stop to prevent the default score change.

onUpdateScore

function onUpdateScore(miss:Bool)

Fired after the score/hit/miss counters are updated.

Frame Updates

onUpdate

function onUpdate(elapsed:Float)

Fired at the start of every frame's update phase.

onUpdatePost

function onUpdatePost(elapsed:Float)

Fired at the end of every frame's update phase.

onDraw Kathy Engine

function onDraw()

Fired at the start of every frame's draw phase (before super.draw()). Use for custom rendering overlays.

onDrawPost Kathy Engine

function onDrawPost()

Fired at the end of every frame's draw phase (after super.draw()). Last chance to draw things on top.

onBeatHit

function onBeatHit()

Fired on every beat (BPM-aligned, once per beat).

onStepHit

function onStepHit()

Fired on every step (half-beat, twice per beat).

onTweenCompleted

function onTweenCompleted(tag:String)

Fired when a Tween finishes (or is cancelled via cancelTween).

onTimerCompleted

function onTimerCompleted(tag:String, loopsLeft:Int)

Fired when a Timer completes one loop.

onSoundFinished

function onSoundFinished(tag:String)

Fired when a sound finishes playing.

Custom Events

onEvent

function onEvent(name:String, value1:String, value2:String, value3:String, value4:String) → can return Function_Stop

Fired when the chart triggers a custom event. Return Function_Stop to prevent PsychEngine's default event handlers from running.

eventEarlyTrigger

function eventEarlyTrigger(eventName:String, strumTime:Float, value1:String, value2:String, value3:String, value4:String) → can return Function_Stop

Fired before the event actually triggers (pre-trigger hook).

onEventPushed

function onEventPushed()

Fired when an event is added to the queue.

Input

onKeyPress

function onKeyPress(key:String) → can return Function_Stop

Fired when a key is just pressed (same as keyJustPressed). Return Function_Stop to prevent engine default handling.

onKeyRelease

function onKeyRelease(key:String) → can return Function_Stop

Fired when a key is released.

onRawKeyPress Kathy Engine

function onRawKeyPress(key:String) → can return Function_Stop

Fired on raw key press — unlike onKeyPress, this fires even when the game is paused.

onRawKeyRelease Kathy Engine

function onRawKeyRelease(key:String) → can return Function_Stop

Fired on raw key release — same pause-ignoring behavior as onRawKeyPress.

onMouseClick

function onMouseClick(button:String) → can return Function_Stop

Fired when the mouse is clicked. Button: 'left', 'right', 'middle', 'x1', 'x2'.

onButtonPress Kathy Engine

function onButtonPress(button:String) → can return Function_Stop

Fired when a gamepad button is pressed.

onButtonRelease Kathy Engine

function onButtonRelease(button:String) → can return Function_Stop

Fired when a gamepad button is released.

Custom Substate

onCustomSubstateCreate

function onCustomSubstateCreate(tag:String)

Fired when a custom substate is created.

onCustomSubstateUpdate

function onCustomSubstateUpdate(tag:String)

Fired every frame while a custom substate is active.

onCustomSubstateDestroy

function onCustomSubstateDestroy(tag:String)

Fired when a custom substate is destroyed.
