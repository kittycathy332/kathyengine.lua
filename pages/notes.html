Kathy Engine - Lua Script API

Note Functions Kathy Engine

Convenience wrappers for querying and modifying individual notes — no more reflection headaches!

All functions here are KathyEngine-exclusive and not present in the original PsychEngine 1.0.4.
They provide a cleaner alternative to getPropertyFromGroup / setPropertyFromGroup.

getNoteCount

Usage: getNoteCount():Int

Returns the number of alive notes currently in the chart (notes that haven't been destroyed/killed yet).

Examples:

  • debugPrint('Alive notes: ' .. getNoteCount())

getTotalNoteCount

Usage: getTotalNoteCount():Int

Returns the total number of notes pre-loaded in the chart (including already-destroyed ones). This is the raw array length.

getAliveNotes

Usage: getAliveNotes():Array<Int>

Returns a table containing the indices of all alive notes. Handy for iterating over notes without worrying about destroyed array holes.

Examples:

  • for i, idx in ipairs(getAliveNotes()) do debugPrint('Note at index: ' .. idx) end

getNoteProperty

getNoteProperty(index:Int, property:String):Dynamic

Reads a specific property from a note at the given index. Supports direct access for common properties and falls back to reflection for anything else.

  • index - Index of the note in the notes array.
  • property - Property name to read (see list below).

Supported properties: noteData, strumTime, noteType, isSustainNote, mustPress, gfNote, missed, wasGoodHit, canBeHit, tooLate, ignoreNote, x, y, alpha, angle, velocityX, velocityY, hitHealth, missHealth, exists, rating

Examples:

  • local noteAlpha = getNoteProperty(5, 'alpha') - Read alpha of note at index 5.
  • local dir = getNoteProperty(3, 'noteData') - Read direction (0=LEFT, 1=DOWN, 2=UP, 3=RIGHT) of note 3.

setNoteProperty

setNoteProperty(index:Int, property:String, value:Dynamic):Bool

Sets a specific property on a note via reflection. Returns true on success, false if the index is out of bounds.

  • index - Index of the note.
  • property - Property name to set.
  • value - New value.

Examples:

  • setNoteProperty(5, 'alpha', 0.3) - Makes note 5 semi-transparent.
  • setNoteProperty(3, 'missed', true) - Manually marks note 3 as missed.

getNoteData

getNoteData(index:Int):Dynamic

Returns a table with all common properties of the note at once. More efficient than calling getNoteProperty multiple times.

Examples:

  • local n = getNoteData(5)
    debugPrint('dir: ' .. n.noteData .. ' x: ' .. n.x .. ' alpha: ' .. n.alpha)

destroyNote

destroyNote(index:Int):Bool

Kills (destroys) the note at the given index. Returns true on success.

  • index - Index of the note to destroy.

Examples:

  • destroyNote(10) - Removes note at index 10 from play.

getNoteRating

getNoteRating(index:Int):String

Returns the judgement rating string for a note (only meaningful after the note has been judged). Possible values: 'Perfect', 'Great', 'Good', 'Bad', 'Shit', '' (empty if not yet judged).

  • index - Index of the note.
