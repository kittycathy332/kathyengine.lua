Kathy Engine - Lua Script API

Math / Utility Functions Kathy Engine

Common math shortcuts and color helpers that every modder needs — no more hacking through reflection!

All functions here are KathyEngine-exclusive.

distance

distance(a:Dynamic, b:Dynamic, ?c:Dynamic = null, ?d:Dynamic = null):Float

Calculates the Euclidean distance between two points. Two call modes:

  • Two args: distance(obj1, obj2) — computes distance between the midpoints of two FlxObjects (works with boyfriend, dad, gf, or any LuaSprite tag).
  • Four args: distance(x1, y1, x2, y2) — computes distance between two raw coordinates.

Examples:

  • local d = distance(boyfriend, dad) - Distance between BF and opponent.
  • local d = distance(100, 100, 300, 400) - Distance between two raw coords (≈360.5).

angleBetween

angleBetween(a:Dynamic, b:Dynamic, ?c:Dynamic = null, ?d:Dynamic = null):Float

Returns the angle (in degrees) between two points. Same two-call modes as distance.

Result is in degrees, ranging from -180 to 180 (atan2 output, not clamped to 0-360).

Examples:

  • local a = angleBetween(boyfriend, dad) - Angle from BF to opponent.
  • local a = angleBetween(0, 0, 100, 100) - Returns 45 (degrees).

lerp

lerp(a:Float, b:Float, t:Float):Float

Linear interpolation between two values. t=0 returns a, t=1 returns b, t=0.5 returns the midpoint.

  • a - Start value.
  • b - End value.
  • t - Interpolation factor (usually 0..1, but values outside work for extrapolation).

Examples:

  • lerp(0, 100, 0.5) - Returns 50.
  • lerp(0, 100, 1.5) - Returns 150 (extrapolation).

clamp

clamp(v:Float, min:Float, max:Float):Float

Clamps a value to the range [min, max]. If v is below min, returns min; if above max, returns max.

  • v - Value to clamp.
  • min - Minimum allowed value.
  • max - Maximum allowed value.

Examples:

  • clamp(-5, 0, 10) - Returns 0.
  • clamp(15, 0, 10) - Returns 10.
  • clamp(5, 0, 10) - Returns 5 (unchanged).

makeFlxPoint

makeFlxPoint(?x:Float = 0, ?y:Float = 0):Point

Creates a new openfl.geom.Point object. Useful for APIs that require a Point instead of separate x/y values.

Examples:

  • local p = makeFlxPoint(100, 200) - Creates point (100, 200).

hueShift

hueShift(color:String, amount:Float):String

Shifts the hue of a hex color string by a given amount (in degrees). Returns a new hex color string.

  • color - Hex color string, e.g. '#FF6B9D' or '#FF6B9DFF' (with alpha).
  • amount - Hue shift amount in degrees. Use values from -180 to 180.

Examples:

  • hueShift('#FF6B9D', 30) - Shifts hue 30 degrees warmer.
  • hueShift('#00FF00', -90) - Green shifted 90° counter-clockwise → magenta-ish.
